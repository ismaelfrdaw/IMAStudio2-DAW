# IMA Studio - Proyecto React + Vite

Este es un proyecto moderno desarrollado con React y Vite, diseñado para ofrecer una experiencia web rápida y fluida.

## Autores
* **Ismael Franco Ruiz**
* **Mario Crespo Alonso**

## Tecnologías Utilizadas
* **React**: Biblioteca para construir interfaces de usuario.
* **Vite**: Herramienta de construcción ultrarrápida para proyectos web.
* **Tailwind CSS**: Framework de CSS para diseños modernos y responsivos.
* **Framer Motion**: Librería para animaciones fluidas.

## Configuración del Proyecto

Para ejecutar el proyecto localmente, sigue estos pasos:

1. Instala las dependencias:
   ```bash
   npm install
   ```

2. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abre el navegador en [http://localhost:5173](http://localhost:5173).

## Sistema de Diseño

El proyecto sigue una identidad corporativa sólida basada en los siguientes principios de diseño:

### 🎨 Paleta de Colores
| Color | Hexadecimal | Uso sugerido |
| :--- | :--- | :--- |
| **Primary** | `#F37021` | Brand Highlights, Buttons, Active States |
| **Secondary** | `#8E9196` | Subtitles, Form Borders, Muted Text |
| **Charcoal** | `#2D2D2D` | Dark Text, Footer, Dark Mode Elements |
| **Background Light** | `#F9FAFB` | Main Background (Light Mode) |
| **Background Dark** | `#121212` | Main Background (Dark Mode) |

### 🖋️ Tipografía
- **Fuente Principal**: `Inter, sans-serif`
  - Utilizada para todo el cuerpo de texto y títulos para asegurar legibilidad y modernidad.

### 📐 Layout y Grid
- **Grid Responsivo**: La interfaz se adapta automáticamente a diferentes pantallas:
  - **Móvil**: 1 columna.
  - **Tablet**: 2 columnas.
  - **Desktop**: 4 columnas (Grid Layout).
- **Contenedores**: Bordes redondeados (`borderRadius`) con escala de `lg`, `xl`, hasta `3xl` para componentes modales.

### ✨ Animaciones
- Implementadas con **Framer Motion** para transiciones suaves, efectos de scroll (Fade-in) y micro-interacciones en botones y tarjetas.
